# Process Over Product: Faculty Workbook

A single-page, self-paced workbook for the NDMU faculty webinar "Process Over Product: A Faculty Framework for AI-Era Online Assessment Design" (December 3, 2026).

Faculty work through four moves on one of their own assessments:

1. **Skill**: list the operations in the task and ask two questions of each (named in the objective? needed unaided later?) to weight it and mark it *protect and measure* or *open to AI*.
2. **Spot**: place each protected operation on the six-rung Context Ladder, now and after one revision.
3. **Step**: choose one revision from a menu filtered by assessment type and target rung, with Canvas setup notes.
4. **Score**: weight the rubric so the protected work carries the points; the page flags when the finished product outweighs the reasoning.

The summary page prints or saves as PDF, copies the plan as text, and copies a tab-separated row for the workshop's shared board.

## Privacy

Everything stays in the visitor's browser (localStorage). Nothing is sent to a server. Clearing site data clears the work.

## Hosting on GitHub Pages

1. Create a repository (or a folder in your existing pedagogy site) and add `index.html`.
2. In the repository's Settings > Pages, publish from the main branch.
3. Link the Pages URL from Canvas and from the "Next steps" slide.

No build step and no external dependencies.
